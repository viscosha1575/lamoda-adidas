# Lamoda Adidas Server

Node.js backend on Express with PostgreSQL, modular architecture, SQL migrations, and HTTP tests.

## Scripts

- `npm install`
- `npm run db:up`
- `cp .env.example .env`
- `npm run dev`
- `npm test`

## Endpoints

- `GET /`
- `GET /api/health`
- `GET /api/products`
- `GET /api/products/:id`
- `POST /api/products`
